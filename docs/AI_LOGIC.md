AI Logic
Overview

Qandil AI uses a profile-based personalization system to adapt responses.

1. Input Layer
Student questionnaire
User queries (text/voice)
2. Profile Generation

The system creates a profile including:

Knowledge Level (Beginner / Intermediate / Advanced)
Learning Style (Visual / Practical / Theoretical)
Preferences (short answers, detailed explanations, etc.)
3. AI Processing

When a student asks a question:

Retrieve student profile
Modify prompt based on:
Difficulty level
Learning style
Send to AI model
Generate personalized response
4. Output Adaptation
Simplifies or expands explanation
Uses analogies
Adds examples based on user context
5. Continuous Learning
Updates profile based on:
Questions asked
Performance
Interaction patterns
Future Improvements
Fine-tuned AI models
Reinforcement learning from user 
Adaptive curriculum generation
