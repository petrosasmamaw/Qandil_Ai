Qandil AI

Personalized AI learning assistant that adapts to each student's knowledge level, learning style, and local context.

🧠 The Problem

Education systems treat all students the same — but:

Students learn at different speeds
Explanations are often too complex or too simple
No personalization based on understanding
Limited accessibility (especially voice-based learning)
💡 Our Solution

Qandil AI is an intelligent learning system that:

Understands each student through a questionnaire
Builds a dynamic learning profile
Adapts explanations to the student’s level
Uses local and relatable analogies
Supports voice interaction
✨ Key Features
🧑‍🎓 Student Profiling
Detects knowledge level
Identifies learning style
Stores personalized preferences
🤖 Personalized AI Chatbot
Answers based on student level
Adjusts explanation depth
Uses simple or advanced language
🎤 Voice Interaction
Ask questions using voice
Get answers in voice
📄 Smart Learning Content
Convert PDFs or courses into:
Simplified explanations
Personalized summaries
🌍 Localized Learning
Uses real-life examples familiar to the student
⚙️ How It Works
Student completes a questionnaire
System builds a learning profile
AI uses this profile to generate responses
System updates profile continuously
🛠 Tech Stack
Frontend: Next.js, React
Backend: API Routes / Node.js
Database: MongoDB / Supabase
AI: OpenAI / Prompt Engineering
Voice: Speech APIs (planned/integrated)
